# Borrower Copilot

> A borrower-first self-assessment that helps Indian borrowers walk into a lender better informed.

Borrower Copilot helps borrowers answer four questions before accepting a loan:

1. **Should I borrow at all?**
2. **How much is a lender likely to sanction?**
3. **How much can I safely carry?**
4. **What rate and EMI should I negotiate for?**

The goal is not to predict a lender's actual approval decision. It is to give the borrower a transparent and conservative benchmark they can use before accepting a loan offer.
